# Counting: one to two, Cross-Branch format

50 visually grounded QA pairs following Section 3.1 and Appendix A.2 of [Cross-Branch Steering](https://arxiv.org/abs/2607.26411).
Positive: two; negative: one. Capture the last answer token without padding.
These are original examples, not the released UMMSteer dataset. The paper does not provide its counting pairs or exact input serialization; `Answer:` is our separator.
